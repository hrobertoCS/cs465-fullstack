<h1 align = "center">Travlr Getaways</h1>

<p align = "center">Full-stack travel package application</p>

<p align = "center">Built using MongoDB, Express.js, Angular, and Node.js</p>

<h2 >Features</h2>


- Administrator interface to edit trip packages
- CRUD operations using MongoDB and Mongoose
- User registration and login using JWT authentication
- REST API connects frontend to database
